Updated 20266 min read

GTA III cheat codes are entered directly from the keyboard during gameplay. In a browser build, click the game viewport first so keyboard focus belongs to the canvas, then type the code without opening a text box.

Browser input tips

  • Click the game canvas before typing a cheat.
  • Type the code as a continuous sequence; do not use a search field or browser shortcut.
  • If a shortcut is intercepted by the browser, return focus to the game and try again.
  • Save before experimenting with chaos or pedestrian cheats because unusual world state can interfere with missions.

Use cheats carefully during missions

Some cheats alter traffic, pedestrians or wanted behavior globally. That can make scripted missions behave differently from normal play. For a clean story run, use cheats mainly while free-roaming and reload a normal save if a mission starts behaving strangely.
