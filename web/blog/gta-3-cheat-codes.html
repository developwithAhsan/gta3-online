GTA 3 Cheat Codes for PC and Browser: Complete GTA III List

Updated Sep 22, 202612 min readGTA III Browser Editorial

GTA III PC-style cheats are typed during gameplay; use them carefully because some world-state effects can persist in a session.

GTA III's classic PC cheats are short text strings typed while the game is running. In the re3 browser build, the same idea applies when keyboard input reaches the game canvas. Cheats are useful for experimentation, but they can also disrupt missions or leave the world in a chaotic state, so keep important progress separate from a heavily cheated session.

How to enter cheats in the browser version

  1. Start GTA III and reach gameplay.
  2. Click inside the canvas so keyboard focus belongs to the game.
  3. Type the cheat continuously; do not open a browser search box.
  4. Watch for the in-game confirmation/effect.
  5. If nothing happens, release pointer lock with Escape, click back into the game and retry.

The browser launcher should not need a separate cheat input field for classic PC-style codes because they are intended to arrive as normal keyboard events.

Cheats and saves

Some cheats can change the world in ways that are undesirable for normal progression. If you care about a clean completion run, use cheats in a disposable session or separate save. Browser-local save behavior can also differ by build, so do not assume a cache reset will undo an in-game world state already written to a save.

Cheats versus performance problems

Pedestrian, weapon and vehicle-chaos cheats can substantially increase the amount of activity on screen. If FPS drops only after enabling chaos cheats, that is not the same as the base game failing to run.

For performance testing, compare a clean session at the same location and FPS cap before changing browser settings.

Version note: Original GTA III, later ports and remastered editions can differ in controls, performance and some game behavior. This site focuses on the original-style re3 browser runtime unless stated otherwise.
