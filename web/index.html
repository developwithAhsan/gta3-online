    ABOUT THE GAME
    
            
    GTA III: the game that opened Liberty City
    
            
    Grand Theft Auto III follows Claude, a silent criminal trying to survive and climb through Liberty City's underworld after a robbery goes wrong. The city is divided into three major areas — Portland, Staunton Island and Shoreside Vale — with missions, gangs, vehicles, weapons and side activities spread throughout the map.
    
            
    This browser project focuses on bringing the open-source re3 runtime to WebAssembly. The launcher handles browser-specific tasks such as persistent archive caching, game-file validation, canvas sizing, fullscreen mode, input diagnostics and save synchronization.
    
          
    

          
    
            
    BROWSER FEATURES
    
            
    Built around persistent local game storage
    
            
    
              
    OPFS Cache
    The compressed archive can be saved in private browser storage so the large network download is not repeated on every visit.
    
              
    Background Worker
    The download pipeline runs through a worker and reports progress while the site remains responsive.
    
              
    Asset Validation
    The launcher checks the required GTA III data files and important level references before enabling the engine.
    
              
    Runtime Diagnostics
    Open the Diagnostics panel to inspect boot stages, WebGL/runtime status, frame timing and input information.
    
              
    Fullscreen Play
    Use the Fullscreen button to expand the game viewport and let the canvas resize to your display.
    
              
    Browser Saves
    The save subsystem provides browser-side save handling and manual sync tools in the runtime panel.

    Frequently Asked Questions
    
            
    
              
    
                What does Download & Play do?+
                
    It downloads the configured authorized ZIP through the asset proxy, saves the compressed archive in OPFS, extracts relevant game data into the WebAssembly runtime, validates the files and then starts GTA III automatically.
    
              
    
              
    
                Will the game ZIP download every time?+
                
    No. When OPFS persistence is available and the cached archive remains in browser storage, later visits reuse it. The archive still has to be read and extracted into the runtime's in-memory filesystem for the current session.
    
              
    
              
    
                Why can the first setup take longer?+
                
    The first run includes a network download, browser storage writes, ZIP decompression and validation. Later runs skip the full network download when the OPFS cache is valid.
    
              
    
              
    
                What should I do if the screen is black or startup stops?+
                
    Open Diagnostics and inspect the boot stage, runtime log and asset validation status. A hard refresh can also clear stale page code, but clearing the cached ZIP is only recommended if validation says the archive is incomplete or incompatible.
    
              
    
              
    
                Can I use my own GTA III files instead?+
                
    Yes. The launcher keeps local folder and ZIP options. Select a compatible legally obtained GTA III installation or ZIP and the launcher will validate it before enabling Play.
    
              
    
              
    
                Is this an official Rockstar website?+
                
    No. This is an independent browser project using the open-source re3 runtime. GTA III and related names and trademarks belong to their respective owners.
