Accessibility

We aim to keep the editorial parts of GTA III Browser readable with semantic headings, keyboard-accessible links and controls, descriptive alternative text for informative images and responsive layouts.

Game runtime

The WebAssembly game runtime inherits accessibility limitations from the underlying game engine. Browser controls such as fullscreen, FPS limit and future touch-control preferences are provided separately where possible.

Content improvements

If a guide image carries information, the page also provides nearby text so the article remains understandable without relying on the image alone.
